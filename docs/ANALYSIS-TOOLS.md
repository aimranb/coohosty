# Analysis tool presentation

The editable source is `src/config/analysis-tools.json`. Translated copy lives under `analysisTools` in all three message files. The cards link to each provider and do not connect APIs or activate subscriptions. PriceLabs and AirDNA were requested as tools used by the business. Beyond is explicitly marked as complementary; its presence does not claim existing business usage.

Provider capabilities were checked against these official sources:
- PriceLabs: https://hello.pricelabs.co/ (dynamic pricing and market dashboards).
- AirDNA: https://www.airdna.co/ (market research and competitor comparison).
- Beyond: https://beyondpricing.com/try/market-insights-overview (market insights).

Brand marks currently use Google's domain favicon service next to always-visible provider names. These are temporary remote assets, not locally bundled official wordmarks. Downloads and visual asset verification were unavailable because outbound shell connections are blocked in this workspace. Replace each `logo` URL with an approved local brand asset for production. Only the image origin `https://www.google.com` was added to CSP; no third-party script was added. Provider trademarks remain their owners' property; the website states there is no official affiliation.
